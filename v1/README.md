# Волк и яйца — v1 (исходная версия)

Первая, простая версия игры: один файл `game.py` и три картинки. Сохранена без изменений
для сравнения с [v2](../v2/README.md).

## Что внутри

| Файл | Что это |
|---|---|
| `game.py` | вся игра, около 200 строк на pygame |
| `wolf.png` | волк с корзиной, 40×70 |
| `egg.png` | яйцо, 20×20 |
| `pit.png` | «яма» в центре — плита со сковородками, 175×325 |

## Как играть

- Четыре ветки (две сверху, две снизу), яйца катятся по ним к центру.
- Стрелки переставляют волка между четырьмя позициями (только по горизонтали
  и вертикали, без диагоналей). Esc — выход.
- Пойманное яйцо — +1 очко, каждые 10 очков растёт уровень и скорость яиц.
- Яйцо, упавшее в «яму», отнимает жизнь. Жизней 10; когда они кончаются, на экране
  появляется «YOU LOSE !!», и через 3 секунды игра закрывается.

## Запуск (Windows)

Нужны Python 3 и pygame:

```powershell
py -m pip install pygame
cd v1
py game.py
```

Запускать нужно **из папки `v1`**: картинки загружаются по относительным путям.

## Известные ограничения

- Если за один кадр поймано или упущено несколько яиц, засчитывается одно.
- Сложность растёт линейно, звука нет, фон статичный.
- В конце игра на 3 секунды замирает (окно может показать «Не отвечает»).

Всё это переработано в [v2](../v2/README.md).
